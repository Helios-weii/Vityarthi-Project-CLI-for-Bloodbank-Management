# Design Notes

## Use Case

Users can:
- Manage donors
- Manage blood inventory
- Register hospitals
- Create blood requests
- Search records
- View reports

## Main Classes

- Donor
- Inv
- Hos
- Search
- Report

## Storage

- donors.dat: donor records
- inventory.dat: blood group and units
- hospitals.dat: hospital details
- requests.dat: hospital blood requests
