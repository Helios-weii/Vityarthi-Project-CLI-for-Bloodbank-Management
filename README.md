# Blood Bank Management System

A simple Python project for managing donors, blood stock, hospitals and blood requests.

## Run

```bash
python main.py
```

No external packages are needed.

## Modules

- Donor management
- Blood inventory
- Hospital and blood requests
- Search
- Reports
- File handling

## Storage

The project uses Python `pickle` and `.dat` files for local storage.

Demo records are included in the `data` folder.

## Python Concepts

Functions, classes, modules, lists, dictionaries, loops, conditions, file handling, pickle and CRUD operations.
