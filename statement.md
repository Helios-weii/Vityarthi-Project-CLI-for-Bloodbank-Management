# Project Statement

## Problem

Keeping donor and blood stock records manually can make searching and updating information difficult.

## Objective

To create a simple Python-based system for managing donors, blood stock, hospitals and blood requests.

## Users

- Blood bank staff
- Hospital staff
- Administrative users

## Main Modules

1. Donor Management
2. Blood Inventory
3. Hospital and Requests
4. Search
5. Reports
6. File Management
